# Portfolio Website Documentation

This project is a personal portfolio website for Sawan Kumar. It is built as a single-page responsive web page using HTML, CSS, Bootstrap, JavaScript, and custom styling.

## Overview

The site showcases:
- Personal introduction and profile summary
- Contact details and social links
- Education timeline
- Skills section with progress bars and categories
- Project highlights
- Internship experience
- Achievements and certifications

## Tech Stack

- HTML5
- CSS3
- Bootstrap 3
- JavaScript
- jQuery
- Font Awesome icons

## How to Run

Open `index.html` in a browser.

For a local preview, you can also use a simple web server in the project folder, such as:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

To personalize the portfolio:

- Update the name and profile details in `index.html`
- Replace the profile image in `images/sawan.jpg`
- Change colors, typography, spacing, and layout in `styles.css`
- Update project, education, skills, and achievement content in the relevant sections of `index.html`
- Replace social links with your own profiles
